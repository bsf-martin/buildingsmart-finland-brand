The buildingSMART Finland lockup is used in white on dark grounds and in Deep Navy on light grounds. It is never recoloured in Mint and never placed on a busy image without a solid panel behind it.

Clear space Proposed

Keep a margin of x on every side, where x is half the height of the mark. Nothing — text, edges, other logos — enters this zone.

Minimum size Proposed

Below these sizes the wordmark loses legibility. Use the mark alone when space is tighter.

Typography

Three families cover everything. Figtree leads headings and UI, Source Sans 3 carries reading text, and JetBrains Mono marks every technical identifier. Hierarchy comes from size and weight, not colour.

By medium

Web & HTML

  • Figtree — headings H1–H6, UI, labels, navigation.
  • Source Sans 3 — all running body text.
  • Source Serif 4 italic — pull quotes and callouts.
  • Load via Google Fonts — no local dependency.

PowerPoint

  • Figtree carries all slide text, body included. Minimum 18pt.
  • Source Serif 4 italic — callouts and pull quotes only. Never upright.
  • Fonts are embedded; editors must also install them.

Word (.docx)

  • Figtree headings via named styles (27pt → 10pt). No manual overrides.
  • Source Sans 3 — Normal style at 12pt.
  • Caption 10.5pt; JetBrains Mono character style at 10pt.
  • The .dotx does not embed fonts.

JetBrains Mono — all media

  • Schema names, file types, versions: IFC4.3 IfcWall BCF 3.0
  • Never decorative. Arial, Calibri and Times New Roman are forbidden in distributed materials.

05
Guidance

Do / Don't

Four rules that protect the system. Each violation erodes the clarity and distinction the palette and type are designed to create.

1

One accent per composition

✓ Do
IFC4.3 Released

The latest version of the IFC schema introduces significant improvements to infrastructure modelling.

Single Mint element — the CTA. Everything else is Navy and Charcoal.
✗ Don't
IFC4.3 Released

The latest version of the IFC schema introduces significant improvements to infrastructure modelling.

Mint heading and Mint button. The accent loses its power when it appears twice.
2

Figtree and Source Sans 3 only

✓ Do
Open BIM Standards

Interoperability begins with a shared language for building data.

Figtree heading with Source Sans 3 body — the correct pairing.
✗ Don't
Open BIM Standards

Interoperability begins with a shared language for building data.

Arial heading with Times New Roman body. System fonts are forbidden in distributed materials.
3

Use approved colour pairings only

✓ Do
Section label

Charcoal (#38363D) on white: 11.5:1 contrast ratio.

Charcoal on white passes AAA (11.5:1). Slate passes AAA for the label (9.1:1).
✗ Don't
Section label

Silver (#C8C6C5) on white: 1.7:1 — fails all WCAG criteria.

Silver on white fails WCAG (1.7:1). Silver is for borders and dividers — never for text.
4

Mint is an accent, not a surface

✓ Do
Active
Mint as a small tag, active indicator or dot. Contained and purposeful.
✗ Don't

Body text on a full Mint background panel.

Mint as a large background surface. It overwhelms the composition and reads as decoration.
